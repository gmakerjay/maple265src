==============================================================================
             คู่มือการใช้งาน MapleStory Server (Zero-Install Portable)
==============================================================================

✨ เซิร์ฟเวอร์นี้เป็นระบบ Portable 100% (Zero-Install):
- ไม่ต้องติดตั้ง Java (JDK) ลงในเครื่อง (มี Portable JDK 21 ในโฟลเดอร์)
- ไม่ต้องติดตั้ง Apache Maven (มี Portable Maven ในโฟลเดอร์)
- ไม่ต้องติดตั้ง MySQL หรือ MariaDB ลงในเครื่อง! (มี Portable MariaDB ในโฟลเดอร์)
- ข้อมูลตัวละคร, เลเวล, ไอเทม, เงิน Mesos จะเซฟลงใน mariadb\data\ ตลอดเวลา

------------------------------------------------------------------------------
วิธีเริ่มเล่น (ง่ายที่สุดในคลิกเดียว):
------------------------------------------------------------------------------
1. ดับเบิลคลิก "1_Start_Server.bat"
   - ระบบจะเปิด Portable MariaDB Engine ให้อัตโนมัติ (พอร์ต 3306)
   - หากเปิดใช้งานครั้งแรก ระบบจะสร้างฐานข้อมูล vietmaple ให้ทันที
   - ระบบจะเปิดรัน MapleStory Server (Login, API, Channels 1-10)
2. เมื่อหน้าจอขึ้น "Finished Loaded WZ data" และ "ready for connections"
3. ก๊อปปี้ไฟล์ทั้งหมดในโฟลเดอร์ "Client_Patch_Files" ไปวางในโฟลเดอร์เกม MapleStory v265
4. ดับเบิลคลิก "Run_Game.bat" หรือ "Launcher.exe" เพื่อเข้าเล่นเกมได้ทันที!

------------------------------------------------------------------------------
วิธีปิดเซิร์ฟเวอร์อย่างปลอดภัย (Safe Shutdown):
------------------------------------------------------------------------------
- ดับเบิลคลิก "3_Stop_Server.bat"
  (ระบบจะปิดเซิร์ฟเวอร์และสั่ง Flush บันทึกข้อมูล MariaDB ลงดิสก์อย่างปลอดภัย 100%)

------------------------------------------------------------------------------
ไฟล์สำคัญภายในโฟลเดอร์:
------------------------------------------------------------------------------
- 1_Start_Server.bat        : เปิดเซิร์ฟเวอร์ + ฐานข้อมูลอัตโนมัติในคลิกเดียว
- 2_Build_Server.bat        : คอมไพล์ซอร์สโค้ดใหม่ด้วย Maven + JDK 21
- 3_Stop_Server.bat         : ปิดเซิร์ฟเวอร์และ MariaDB อย่างปลอดภัย
- 4_Server_Control_Panel.bat: เมนูควบคุมรวม (Start / Stop / Restart / Build / Config)
- Import_Database.bat       : เครื่องมือนำเข้าฐานข้อมูล backup.sql (หากต้องการรีเซ็ต)
- server.properties         : ไฟล์ตั้งค่าอัตราคูณ Rate EXP, Meso, Drop, IP และ Port
- Client_Patch_Files/       : ไฟล์ Launcher + Localhost.dll สำหรับเข้าเกม
