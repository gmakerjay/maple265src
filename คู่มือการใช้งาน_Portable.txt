==============================================================================
             คู่มือการใช้งาน MapleStory Server Portable Edition
==============================================================================

ผู้ใช้มีหน้าที่เพียง:
1. ติดตั้งโปรแกรม MySQL หรือ MariaDB
2. นำเข้าฐานข้อมูล backup.sql (สามารถดับเบิลคลิกไฟล์ Import_Database.bat ได้เลย)
3. ตรวจสอบรหัสผ่าน MySQL ในไฟล์ server.properties (ค่าเริ่มต้นคือ password=root หรือแก้ตามเครื่องคุณ)
4. ดับเบิลคลิก 1_Start_Server.bat เพื่อเริ่มเล่นได้ทันที!

------------------------------------------------------------------------------
ไฟล์สำคัญภายในโฟลเดอร์:
------------------------------------------------------------------------------
- 1_Start_Server.bat        : รันเซิร์ฟเวอร์ MapleStory (ไม่ต้องลง Java ในเครื่อง)
- 2_Build_Server.bat        : Rebuild โค้ดใหม่ด้วย Maven (มี Maven + JDK 21 ในโฟลเดอร์แล้ว)
- 3_Stop_Server.bat         : สั่งปิดเซิร์ฟเวอร์และเคลียร์พอร์ต
- 4_Server_Control_Panel.bat: เมนูควบคุมรวม (Start / Stop / Restart / Build / Config)
- Import_Database.bat       : เครื่องมือนำเข้าฐานข้อมูล vietmaple อัตโนมัติ
- server.properties         : แก้ไขการตั้งค่าฐานข้อมูล, IP (127.0.0.1), และ Port

------------------------------------------------------------------------------
