==============================================================================
        วิธีนำไฟล์ชุดนี้ไปใช้งานบนเครื่องอื่น (Client Patch for Other PC)
==============================================================================

ไฟล์ทั้งหมดในโฟลเดอร์นี้ประกอบด้วย:
1. Install_Client_Patch.bat - ตัวติดตั้งอัตโนมัติ 1-Click (ตรวจหาโฟลเดอร์เกม Steam / Nexon แล้ววางไฟล์ให้อัตโนมัติ)
2. Launcher.exe             - ตัวรันเกม x64 พร้อมระบบ Auto-Elevation (Admin) และ Detours Injection
3. Localhost.dll            - ตัว Hook ดักจับ Socket, บายพาส NMCO, บายพาส Multi-Client, แก้บั๊ก Memory Crash
4. launcher.ini             - ไฟล์ตั้งค่า IP / Port เซิร์ฟเวอร์ และบัญชีผู้ใช้
5. Run_Game.bat             - สคริปต์สำหรับกดรันเกมแบบคลิกเดียว
6. Change_IP_or_Account.bat - เครื่องมือสลับ IP และเปลี่ยนรหัสผ่าน / บัญชีเข้าเล่น

------------------------------------------------------------------------------
ขั้นตอนการติดตั้งบนเครื่องอื่น:
------------------------------------------------------------------------------
วิธีที่ 1 (แนะนำและง่ายที่สุด):
- ดับเบิลคลิกที่ไฟล์ "Install_Client_Patch.bat" ระบบจะตรวจหาโฟลเดอร์ MapleStory ในเครื่องและติดตั้งให้ทันที

วิธีที่ 2 (วางเองแบบ Manual):
1. คัดลอก (Copy) ไฟล์ทั้งหมดในโฟลเดอร์นี้
2. นำไปวางทับ (Paste) ในโฟลเดอร์ตัวเกม MapleStory v265 ของเครื่องนั้น (โฟลเดอร์เดียวกับที่มีไฟล์ MapleStory.exe)

------------------------------------------------------------------------------
การตั้งค่าในไฟล์ launcher.ini:
------------------------------------------------------------------------------
[Server]
IP = 127.0.0.1      <- ใส่ IP ของเครื่องเซิร์ฟเวอร์ (ถ้าเล่นเครื่องเดียวกับเซิร์ฟเวอร์ใช้ 127.0.0.1, ถ้าเล่นข้ามเครื่องให้ใส่ IP ของเครื่องเซิร์ฟเวอร์ เช่น 192.168.1.xxx หรือ IP จาก Radmin VPN / Hamachi)
Port = 8484         <- พอร์ต Login เซิร์ฟเวอร์
ApiPort = 8483      <- พอร์ต API เซิร์ฟเวอร์สำหรับขอ Session Token

[Account]
AutoLogin = 1       <- 1 = ล็อกอินผ่าน Server API อัตโนมัติ (แนะนำ), 0 = ใช้ UserID ตรง
Username = admin    <- ชื่อไอดีในฐานข้อมูล (users table)
Password = admin    <- รหัสผ่านในฐานข้อมูล
UserID = 1          <- ไอดีสำรอง (1 = admin, 2 = admin1, 3 = asura, 4 = maigal)

------------------------------------------------------------------------------
การเข้าเล่น:
------------------------------------------------------------------------------
- ดับเบิลคลิกที่ไฟล์ Run_Game.bat หรือ Launcher.exe
- เมื่อมีหน้าต่าง UAC ถามสิทธิ์ ให้กด "Yes" เพื่อเริ่มเล่นเกมได้ทันที
