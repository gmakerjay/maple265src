[!] 100% ZERO-INSTALL / FULLY PORTABLE:
    - ไม่ต้องติดตั้ง MySQL หรือ MariaDB ลงใน Windows
    - ไม่ต้องติดตั้ง Java หรือ JDK ลงใน Windows
    - แตกไฟล์ไว้ที่ไหนก็ได้ (Drive C:, D:, E:, หรือ Flash Drive) ดับเบิ้ลคลิกรันได้ทันที
    - ข้อมูลตัวละคร, ไอดี, เซฟเกมทั้งหมดจะถูกบันทึกอัตโนมัติไว้ในโฟลเดอร์:
      mariadb\data\

==============================================================================
[1] วิธีเปิดเซิร์ฟเวอร์ (START SERVER):
==============================================================================
    - ดับเบิ้ลคลิก: 1_Start_Server.bat
    - ระบบจะเปิด Portable MariaDB (Port 33066) และเปิดเซิร์ฟเวอร์ MapleStory ให้อัตโนมัติ
    - รอจนหน้าต่างเซิร์ฟเวอร์แสดงข้อความ:
      "MapleStory V265 Server is online and ready for connections!"

==============================================================================
[2] วิธีปิดเซิร์ฟเวอร์อย่างปลอดภัย (STOP SERVER):
==============================================================================
    - ดับเบิ้ลคลิก: 3_Stop_Server.bat
    - ระบบจะสั่ง Save ข้อมูลตัวละครทั้งหมด และ Flush ลงฐานข้อมูล MariaDB ก่อนปิดอย่างปลอดภัย

==============================================================================
[3] เมนูควบคุมเซิร์ฟเวอร์แบบรวม (CONTROL PANEL):
==============================================================================
    - ดับเบิ้ลคลิก: 4_Server_Control_Panel.bat
    - มีเมนูควบคุมครบวงจร:
      [1] Start Server
      [2] Restart Server
      [3] Stop Server
      [4] Start ONLY MariaDB (เปิดเฉพาะฐานข้อมูล)
      [5] Stop ONLY MariaDB (ปิดเฉพาะฐานข้อมูล)
      [6] Open MariaDB Console (เปิดหน้าต่างพิมพ์คำสั่ง SQL ทันที)
      [7] Backup Database (สำรองฐานข้อมูลออกมาเป็นไฟล์ .sql อัตโนมัติ)
      [8] Reset / Re-import Database (ล้างข้อมูลและนำเข้าฐานข้อมูลเริ่มต้น)
      [9] Account Registration & Manager (สมัครไอดี / ดูรายชื่อ / ให้สิทธิ์ GM / เสกของ)
      [10] Configure Server IP (ตั้งค่า IP สำหรับเล่นคนเดียว หรือเล่นผ่าน Radmin VPN / วง LAN)
      [11] Edit Server Rates (ปรับ EXP, Drop, Meso ใน Notepad)
      [12] Port Diagnostic (ตรวจสอบพอร์ตชนและสลับพอร์ตสำรองอัตโนมัติ)
      [13] Open Client Patch Files (เปิดโฟลเดอร์ไฟล์สำหรับเครื่องผู้เล่น/ลูกข่าย)

==============================================================================
[4] ระบบสมัครไอดี & สิทธิ์ GM (ACCOUNT SYSTEM):
==============================================================================
    - วิธีที่ 1 (Auto-Register):
      เมื่อเปิดเซิร์ฟเวอร์แล้ว ให้เปิดเกมและพิมพ์ Username กับ Password ที่ต้องการได้เลย
      ระบบจะทำการบันทึกและสมัครไอดีให้อัตโนมัติในครั้งแรกทันที!
    - วิธีที่ 2 (Create_Account.bat):
      ดับเบิ้ลคลิก Create_Account.bat สามารถสมัครไอดีใหม่, ตั้งสิทธิ์ GM/Admin (เพื่อเสกของ),
      ดูรายชื่อไอดีทั้งหมดในเครื่อง และรีเซ็ตรหัสผ่านได้ในที่เดียว

==============================================================================
[5] การเล่นผ่าน Radmin VPN / วง LAN / อินเทอร์เน็ตเดียวกัน:
==============================================================================
    - เซิร์ฟเวอร์รองรับการเล่นพร้อมกัน:
      * เครื่องโฮสต์เล่นผ่าน 127.0.0.1 ได้ตลอดเวลา
      * เพื่อนในวง LAN หรือ Radmin VPN เชื่อมต่อผ่าน IP วงแลนเข้ามาเล่นพร้อมกันได้ทันที
    - การตั้งค่า IP ฝั่งเครื่องโฮสต์ (คนเปิดเซิร์ฟเวอร์):
      * เข้า 4_Server_Control_Panel.bat เลือกเมนู [10]
      * หรือแก้ไขใน server.properties บรรทัด `server.ip=IP_เครื่องคุณ`
    - การตั้งค่า IP ฝั่งเพื่อน (เครื่องลูกข่าย):
      * ส่งโฟลเดอร์ Client_Patch_Files ให้เพื่อนนำไปวางทับในตัวเกม MapleStory
      * เพื่อนดับเบิ้ลคลิก Change_IP_or_Account.bat แล้วกรอก IP ของเครื่องโฮสต์ จากนั้นเข้าเล่นได้ทันที!
