==============================================================================
               คู่มือการตั้งค่าเล่นแบบ LAN / วงแลนเดียวกัน
               MapleStory v265 Portable Server Runner
==============================================================================

[บทนำ]
การเล่นแบบ LAN คือการให้เครื่องเพื่อน (เครื่องลูก) เชื่อมต่อเข้ามาเล่นกับเครื่องที่คุณเปิดเซิร์ฟเวอร์ (เครื่องแม่) 
โดยใช้สาย LAN เดียวกัน, Wi-Fi บ้านเดียวกัน หรือเชื่อมต่อผ่าน Radmin VPN / Hamachi วงเดียวกัน
โฟลว์การทำงานถูกออกแบบมาให้เรียบง่ายที่สุด:
"เครื่องแม่สร้างไอดีไว้รอ -> เครื่องลูกเปลี่ยน IP ชี้มาที่เครื่องแม่ -> ล็อกอินเข้าเล่นได้ทันที"

------------------------------------------------------------------------------
[ส่วนที่ 1] ขั้นตอนสำหรับเครื่องแม่ (Host - คนเปิดเซิร์ฟเวอร์)
------------------------------------------------------------------------------

1. เปิดเซิร์ฟเวอร์:
   - ดับเบิ้ลคลิกไฟล์ "1_Start_Server.bat"
   - รอจนหน้าต่างคอนโซลขึ้นว่าระบบพร้อมทำงานเรียบร้อย

2. ดูหมายเลข IP วง LAN ของเครื่องตนเอง:
   - กรณีเล่นในบ้านเดียวกัน (สาย LAN / Wi-Fi เดียวกัน):
     เปิด Command Prompt (พิมพ์ cmd ในช่องค้นหาของ Windows)
     พิมพ์คำสั่ง: ipconfig แล้วกด Enter
     มองหาบรรทัด "IPv4 Address" เช่น 192.168.1.50
   - กรณีเล่นข้ามบ้าน (ผ่าน Radmin VPN หรือ Hamachi):
     ดูที่ [ส่วนที่ 3] ด้านล่าง
   - นำหมายเลข IP นี้ไปบอกเพื่อน

3. สร้างไอดีให้เพื่อน:
   - ดับเบิ้ลคลิกไฟล์ "Create_Account.bat"
   - เลือกเมนู [1] Create New Account
   - ตั้งชื่อไอดี (Username) และรหัสผ่าน (Password) ให้เพื่อนตามต้องการ
   - เมื่อสร้างเสร็จแล้ว ให้นำไอดีและรหัสผ่านนี้ไปบอกเพื่อน

4. ส่งไฟล์สำหรับเข้าเกมให้เพื่อน:
   - ก๊อปปี้ไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์ "Client_Patch_Files" ส่งให้เพื่อน
     (หรือส่งเฉพาะไฟล์ Launcher, Localhost.dll, launcher.ini, Change_IP_or_Account.bat, Run_Game.bat)

------------------------------------------------------------------------------
[ส่วนที่ 2] วิธีดูค่า IP และ Port จากเครื่องหลัก เพื่อนำไปใส่ใน launcher.ini
------------------------------------------------------------------------------

ในไฟล์ launcher.ini ของเครื่องลูก จะมี 3 ค่าหลักที่ต้องตรงกับเครื่องแม่:
- IP
- Port (พอร์ต Login)
- ApiPort (พอร์ตระบบบัญชี/Token)

วิธีการดูแต่ละค่าจากเครื่องแม่:

1. วิธีดูหมายเลข IP:
   - ดูจาก ipconfig (กรณี LAN ในบ้าน) หรือดูจากหน้าต่าง Radmin VPN / Hamachi
   - ตัวอย่างเช่น: IP=192.168.1.50 หรือ IP=26.154.20.88

2. วิธีดูพอร์ต Port และ ApiPort:
   - ที่เครื่องแม่ เปิดไฟล์ "server.properties" ด้วย Notepad
   - สังเกต 2 บรรทัดนี้:
     * login.port=8484  --> นำเลข 8484 ไปใส่ใน Port ของ launcher.ini
     * api.port=8483    --> นำเลข 8483 ไปใส่ใน ApiPort ของ launcher.ini
   (หมายเหตุ: โดยปกติ พอร์ต 8484 และ 8483 จะเป็นค่ามาตรฐานตายตัวอยู่แล้ว 
    หากเครื่องแม่ไม่ได้แก้ไขไฟล์ server.properties เครื่องลูกก็ไม่ต้องแก้สองบรรทัดนี้เลย 
    แก้เพียงแค่บรรทัด IP บรรทัดเดียวเท่านั้น)

3. ตัวอย่างการนำค่าไปใส่ในไฟล์ launcher.ini ของเครื่องลูก:
   เปิดไฟล์ launcher.ini ในโฟลเดอร์เกมของเครื่องลูกด้วย Notepad
   แก้ไขส่วนหัวข้อ [Server] ให้ตรงตามนี้:

   [Server]
   IP=192.168.1.50
   Port=8484
   ApiPort=8483

   เมื่อแก้ไขเสร็จแล้ว ให้กด File -> Save (หรือกด Ctrl + S) เพื่อบันทึกไฟล์

------------------------------------------------------------------------------
[ส่วนที่ 3] กรณีเล่นข้ามบ้านผ่าน Radmin VPN หรือ LogMeIn Hamachi
------------------------------------------------------------------------------

หากคุณและเพื่อนอยู่คนละบ้าน คนละอินเทอร์เน็ต สามารถใช้โปรแกรม Radmin VPN (แนะนำ)
หรือ LogMeIn Hamachi เพื่อจำลองให้เสมือนอยู่ในวง LAN เดียวกันได้ทันที โดยไม่ต้องตั้งค่า Forward Port ในเร้าเตอร์:

1. ขั้นตอนฝั่งเครื่องแม่ (Host):
   - เปิดโปรแกรม Radmin VPN (หรือ Hamachi)
   - กดปุ่ม "Create Network" (สร้างห้องเครือข่าย)
   - ตั้งชื่อห้อง (Network Name) และรหัสผ่าน (Password)
   - ดูหมายเลข IP ประจำตัวของเครื่องแม่ที่แสดงตัวเลขใหญ่ๆ อยู่ด้านบนของโปรแกรม:
     * ถ้าใช้ Radmin VPN: IP จะขึ้นต้นด้วย "26.x.x.x" (ตัวอย่าง: 26.154.20.88)
     * ถ้าใช้ Hamachi: IP จะขึ้นต้นด้วย "25.x.x.x" (ตัวอย่าง: 25.88.140.12)
   - ส่งชื่อห้อง รหัสผ่าน และหมายเลข IP นี้ให้เพื่อน

2. ขั้นตอนฝั่งเครื่องลูก (Client - เพื่อน):
   - เปิดโปรแกรม Radmin VPN (หรือ Hamachi) ในเครื่องของตนเอง
   - กดปุ่ม "Join Network" (เข้าร่วมเครือข่าย)
   - กรอกชื่อห้องและรหัสผ่านที่เครื่องแม่ส่งมาให้ เมื่อเข้าห้องสำเร็จจะเห็นไฟสถานะเป็นสีเขียว
   - เปิดไฟล์ "launcher.ini" ในโฟลเดอร์ตัวเกม (หรือใช้ Change_IP_or_Account.bat)
   - นำหมายเลข IP ของเครื่องแม่ (26.x.x.x หรือ 25.x.x.x) มาใส่ในช่อง IP เช่น:

     [Server]
     IP=26.154.20.88
     Port=8484
     ApiPort=8483

   - กด Save แล้วเปิดเกมเข้าเล่นด้วยไอดีที่เครื่องแม่สร้างให้ได้ทันที

3. ข้อควรระวังพิเศษสำหรับ Radmin VPN และ Hamachi:
   - ตรวจสอบสถานะการเชื่อมต่อ: ในหน้าต่าง Radmin/Hamachi ให้คลิกขวาที่ชื่อเครื่องแม่ แล้วเลือก "Ping" 
     หากได้รับสัญญาณตอบกลับ (Reply from...) แสดงว่าระบบเชื่อมต่อถึงกันเรียบร้อย
   - หาก Ping ไม่ขึ้น ให้เครื่องแม่ตรวจสอบ Windows Firewall และกดอนุญาตโปรแกรม Radmin / Hamachi และ Java

------------------------------------------------------------------------------
[ส่วนที่ 4] ขั้นตอนสำหรับเครื่องลูก (Client - เพื่อนที่ต้องการเข้าเล่น)
------------------------------------------------------------------------------

1. ติดตั้งไฟล์เข้าเกม:
   - นำไฟล์ทั้งหมดจากโฟลเดอร์ Client_Patch_Files ไปวางทับลงในโฟลเดอร์ตัวเกม MapleStory v265

2. เปลี่ยน IP ชี้ไปหาเครื่องแม่ (เลือกทำวิธีใดวิธีหนึ่งตามสะดวก):
   - วิธีที่ ก (แนะนำ ง่ายที่สุด):
     ดับเบิ้ลคลิกไฟล์ "Change_IP_or_Account.bat"
     กดเลข 1 แล้วกด Enter
     พิมพ์หมายเลข IP ของเครื่องแม่ (IP ในบ้าน หรือ IP ของ Radmin/Hamachi) แล้วกด Enter
     ระบบจะบันทึกค่าลงใน launcher.ini ให้อัตโนมัติ

   - วิธีที่ ข (ทำผ่านตัว Launcher):
     เปิดโปรแกรม "Launcher.exe" หรือ "Run_Game.bat"
     กดปุ่มรูปเฟือง (Settings) ที่มุมขวาบน
     ในช่อง Server IP ให้พิมพ์หมายเลข IP ของเครื่องแม่ แล้วกด Apply

   - วิธีที่ ค (แก้ไขไฟล์ด้วยตนเอง):
     เปิดไฟล์ "launcher.ini" ด้วยโปรแกรม Notepad แล้วกรอกค่าตาม [ส่วนที่ 2] ด้านบน

3. เข้าเล่นเกม:
   - เปิดโปรแกรม "Launcher.exe" หรือ "Run_Game.bat"
   - กรอกชื่อไอดีและรหัสผ่านที่เครื่องแม่สร้างไว้ให้
   - กดปุ่ม Start Game เพื่อเข้าเล่นได้ทันที

------------------------------------------------------------------------------
[ส่วนที่ 5] ข้อควรระวังและการแก้ไขปัญหา (Troubleshooting)
------------------------------------------------------------------------------

1. ปัญหาเครื่องลูกเชื่อมต่อไม่ได้ (Connection Timeout / Network Error):
   - ให้เครื่องแม่ตรวจสอบ Windows Defender Firewall
   - ให้เครื่องแม่ทำการอนุญาตพอร์ต (Inbound Rules) ดังต่อไปนี้:
     * Port 8483 (API Token Authentication)
     * Port 8484 (Login Server)
     * Port 8585 ถึง 8595 (Channel Servers)
   - หรือทดลองปิด Windows Firewall ชั่วคราวในเครือข่าย Private Network เพื่อทดสอบ

2. ปัญหาเครื่องลูกมองไม่เห็นเครื่องแม่:
   - ให้เครื่องลูกลองเปิด Command Prompt แล้วพิมพ์คำสั่ง:
     ping <IP_เครื่องแม่>
     เช่น: ping 26.154.20.88
   - หากขึ้น "Reply from..." แสดงว่าสัญญาณเชื่อมต่อถึงกันได้ปกติ
   - หากขึ้น "Request timed out" แสดงว่าสาย LAN / Wi-Fi อยู่คนละวง หรือถูก Firewall ของเครื่องแม่บล็อกไว้
